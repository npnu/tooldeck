# ToolDeck

クリップボードの履歴が欲しくて作り始めたら、気づいたらいろんなツールが入っていました。Windows で常駐させて、ショートカットかトレイアイコンからすぐ呼び出す使い方を想定しています。

入っているもの:

- コピーしたテキスト・画像・ファイルの履歴と、よく使う文章のスニペット
- yt-dlp を使った動画ダウンロード（MP4 / MP3、画質指定、プレイリスト、字幕）
- 範囲選択スクリーンショットと、画像からの文字抽出（Tesseract.js）
- 全角/半角、文字コード、改行、Base64、ハッシュなどのテキスト変換
- 画像の変換・リサイズ、PDF の結合・分割、ファイル名の一括変更
- QR コードの作成と読み取り、パスワード生成、カラーコード変換、簡易メモ

ダークテーマが既定です。設定からライトに変えられます。

## ダウンロード

[Releases](https://github.com/npnu/tooldeck/releases) にある `ToolDeck.exe` を1つダウンロードして、好きな場所に置いて起動してください。インストールは不要です。

初回起動時に、ダウンロード機能で使う `yt-dlp.exe` と `ffmpeg.exe` を自動で取ってきます。数十秒から数分かかることがあります。進捗はダウンロード画面と設定画面に出ます。

取得したファイルは `%APPDATA%\tooldeck\bin\` に入ります。手動で `bin/` に置いたものがあれば、そちらが優先されます。自動取得を止めたいときは設定画面のチェックを外してください。

OCR の言語データは初回にネットから取得するので、そのときだけ接続が必要です。

## ショートカット

既定のもの。設定画面から変更できます。

| キー | 動作 |
| --- | --- |
| `Ctrl+Shift+V` | クリップボード履歴 |
| `Ctrl+Shift+D` | ダウンロード画面 |
| `Ctrl+Shift+X` | 範囲キャプチャ |

トレイアイコンのダブルクリックでウィンドウを出し入れできます。閉じるボタンは終了ではなくトレイへ隠す動きです。終了するときはトレイメニューか設定画面からどうぞ。

クリップボードの履歴やメモは `%APPDATA%\tooldeck` の JSON ファイルに保存しています。

## 開発するとき

Node.js 18 以上が必要です。

```powershell
npm install
npm run dev     # Vite と Electron を同時に起動
npm run build   # コンパイルだけ
npm run dist    # インストーラーとポータブル版を作る
```

`npm run dev` は Vite の 5173 番ポートを使います。Electron 単体で起動するとロードに失敗するので、必ず `npm run dev` からどうぞ。

実行ファイルを自分で入れたい場合は `bin/` に `yt-dlp.exe` と `ffmpeg.exe` を置いてください。置かなくても初回起動時に自動で取得されます。

## 自動更新

起動時に GitHub Releases を check して、新しいバージョンがあれば設定画面に「更新あり」と出ます。「更新する」を押すと exe をダウンロードし、再起動して自分のファイルを入れ替えます。インストーラーは不要です。

リリースを作る側は、asset のファイル名を必ず `ToolDeck.exe` にしてください（自前アップデータがこの名前を探します）。Fork して使う場合は `src/main/selfupdate.ts` の `RELEASES_API` を自分のリポジトリに合わせてください。
